# ubuntu-weather-indicator 1.2.3

- Le menu reprend la carte du lieu : mesures à droite, heures du jour en cases, semaine sur demande.

# ubuntu-weather-indicator 1.2.2

- Le menu s’ouvre sur la météo du jour, dans un panneau plus étroit. Les sept jours s’affichent seulement si on les demande.

# ubuntu-weather-indicator 1.2.1

- L’onglet Lieu affiche la ville cochée, la recherche pendant la saisie et la localisation automatique.

# ubuntu-weather-indicator 1.2.0

- Le menu montre les prochaines heures et les sept jours.
- Les couleurs suivent le thème clair ou sombre.
- Les boutons ont un nom pour le lecteur d’écran, et les jours suivent la langue de la session.
- Sans ville, la recherche se fait dans le menu.
- La description du store est aussi en français.

# ubuntu-weather-indicator 1.1.0

- Plusieurs villes enregistrées, avec un choix dans le menu.
- La localisation automatique affiche le nom de la ville.
- La pression est en hectopascals par défaut.
- La recherche de ville se lance pendant la saisie.
- Le menu signale la première heure où la pluie est probable.
- MET Norway sert de prévision de secours si Open-Meteo ne répond pas.

# ubuntu-weather-indicator 1.0.0

Première version installable.

- Extension GNOME Shell 50, sans Electron ni service en arrière-plan.
- Température et icône à côté de l’horloge, menu de prévisions, ville, unités, cache et paquet Debian `all`.
- Environnement officiellement testé : Ubuntu 26.04.1, GNOME Shell 50.1, Wayland.
- Les autres versions majeures de GNOME Shell sont refusées à l’installation.
